# Telegram-бот: помічник психотерапевтки

## Запуск
1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Дізнайтеся Telegram ID психотерапевтки (його покаже, наприклад, @userinfobot).
   **Важливо:** вона має один раз натиснути `/start` у своєму боті, інакше бот не зможе писати їй заявки.
3. Встановіть залежності та запустіть:

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен"
export ADMIN_ID="123456789"
export INSTAGRAM_URL="https://instagram.com/zhara_j"
python bot.py
```

Щоб бот працював постійно, запустіть його на сервері (VPS, Railway, Render тощо).

## Що перевірити в `bot.py` (блок «НАЛАШТУВАННЯ»)
- Підтверджені тарифи: індивідуальна консультація — 35€, пакет із 4 сесій — 120€.
- `CITY`, `CITY_GEN` — місто для очної сесії (зараз Київ).
- `WORKING_HOURS` — за потреби задайте години прийому; якщо значення порожнє, рядок не показується.

Стан запису зберігається в памʼяті (`MemoryStorage`): після перезапуску бота незавершені записи скидаються.
